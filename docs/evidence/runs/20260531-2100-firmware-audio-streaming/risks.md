# Risks

- Brownout, noise, or reboot may appear only during physical amplifier tests.
- Speaker wiring can damage hardware if SPK- is tied to GND.
- Sound spam and night-time disturbance require future quiet-hours policy.
- HTTP audio decoding can increase RAM/flash usage and latency.
- MQTT remains local POC without TLS/authentication.
- Backend has not yet implemented TTS hosting or status ingestion evidence.
